# Assignment 3 – Complex Table

## Description
This project is a Semester Study Timetable created using HTML and CSS. It displays a four-week study schedule with morning and afternoon sessions in a structured table.

## Features
- 20 timetable rows and 10 columns.
- Table caption, header, body and footer.
- Uses `rowspan` and `colspan`.
- CSS variables for colours, spacing and font size.
- Alternate row colours.
- Hover effect on table rows.
- Horizontal scrolling for smaller screens.

## Technologies Used
- HTML5
- CSS3
