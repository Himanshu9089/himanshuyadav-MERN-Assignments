# Assignment 9 – Responsive Gaming Landing Page

## Description
This project is a responsive gaming-themed landing page called **Pixel Arena**. It is designed to provide a modern gaming experience with a dark background, neon colours, game cards, features, and a gaming gallery.

## Features
- Attractive gaming-themed hero section.
- Navigation bar with different sections.
- Popular games section with three game cards.
- Features section highlighting the gaming community.
- Gaming gallery with images.
- Contact section.
- Responsive layout for desktop, tablet, and mobile screens.
- Used Flexbox and CSS Grid for page layouts.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries

## Challenge Faced
Combining CSS Grid and Flexbox to create a well-organized gaming landing page while maintaining responsiveness across desktop, tablet, and mobile screens.

## How to Run
1. Open the project folder.
2. Open `index.html` in a web browser.
3. Make sure you have an internet connection to load the online images.
