# Assignment 2 – Job Application Form

## Description
This project is a Job Application Form created using HTML and CSS. It allows applicants to enter their personal information, job preferences, skills, and other details.

## Features
- Personal information fields
- Gender selection using radio buttons
- Job position selection
- Technical skills using checkboxes
- Resume upload option
- Address and message fields
- Submit and Reset buttons
- Responsive layout for mobile screens

## Technologies Used
- HTML5
- CSS3

## Project Structure
```text
Assignment-2-Job-Application-Form/
├── index.html
├── style.css
└── README.md
```

## Challenges Faced
1. Arranging different form elements properly.
2. Arranging form fields and making the form responsive.

## Learning Outcomes
- Learned to create HTML forms.
- Understood different input types.
- Learned to apply CSS styling.
- Practiced basic responsive design.

## How to Run
1. Open the project folder.
2. Open `index.html` in a web browser.
