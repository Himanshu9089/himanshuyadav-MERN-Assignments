# Assignment 5 – Brew & Bean Café Landing Page

## Description
This project is a business landing page for a fictional café named Brew & Bean. It is created using HTML and CSS. The website showcases the café, its services, gallery, contact form and other information.

## Features
- Hero section with background image.
- Navigation menu with internal links.
- About section introducing the café.
- Three different service cards.
- Gallery section with images.
- Contact form with name, email and message fields.
- Footer with navigation links.
- Hover effects on buttons and links.
- Mobile-friendly layout.

## Technologies Used
- HTML5
- CSS3
