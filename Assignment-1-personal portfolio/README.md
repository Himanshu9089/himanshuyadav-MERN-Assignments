# Assignment 1 – Personal Portfolio

## Description
This project is a basic personal portfolio website created using HTML. It introduces my personal information, skills, education, projects, and contact details.

## Objectives
- Create a basic HTML webpage.
- Add personal resume content.
- Use semantic HTML elements.
- Create internal navigation links.
- Include different types of HTML lists.
- Add images with meaningful alt text.
- Use appropriate HTML meta tags.

## Technologies Used
- HTML5

## Project Structure
```text
Assignment-1-Personal-Portfolio/
├── index.html
└── README.md
```

## Learning Outcome
Through this assignment, I will learn the fundamentals of HTML, semantic elements, navigation, lists, images, and meta tags.

## How to Run
1. Open the project folder.
2. Open `index.html` in a web browser.
